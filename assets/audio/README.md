# 🎧 ضع ملف صوت سورة يس هنا

ضع ملفك الصوتي بصيغة `MP3` داخل هذا المجلد باسم:

    yaseen.mp3

بعدها لا حاجة لتعديل أي شيء — سيعمل تلقائيًا.

## شروط مهمة

- التسمية يجب أن تكون بالضبط `yaseen.mp3`
- الحجم المفضّل أقل من 15 ميجابايت (لأداء أفضل على الجوال)
- استخدم تسجيلًا مرخّصًا أو مصرّحًا باستخدامه
- الصيغ المدعومة في المتصفح: MP3 / M4A / OGG

## بديل: رابط خارجي

إن لم ترغب برفع الملف، افتح `assets/js/config.js`
وضع الرابط في `AUDIO.REMOTE` (يجب أن يبدأ بـ https).

## المسارات الناقلة (Range Requests)

بعض المتصفحات تحتاج دعم `Accept-Ranges` لتشغيل/تقديم الصوت.
- Netlify / Cloudflare Pages: مدعوم تلقائيًا (ملف `_headers` مرفق)
- Apache: مدعوم تلقائيًا (ملف `.htaccess` مرفق)
- GitHub Pages: مدعوم
